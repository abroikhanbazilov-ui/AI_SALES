# 📈 БЛОК 9: UNIT-ЭКОНОМИКА KERAMO BUILD

## Как работает бизнес-модель

```
┌──────────────────────────────────────────────────────────────────┐
│                    KERAMO BUILD UNIT                              │
│         Полный цикл: Продажа → Нарезка → Монтаж на стены        │
└──────────────────────────────────────────────────────────────────┘

     КЛИЕНТ                                           KERAMO BUILD
        │                                                   │
        │  1. Видит рекламу в Instagram/TikTok              │
        │─────────────────────────────────────────────────→│
        │                                                   │
        │  2. Пишет в Direct или звонит                     │
        │─────────────────────────────────────────────────→│
        │                                                   │
        │  3. Менеджер выезжает на замер (бесплатно)       │
        │←─────────────────────────────────────────────────│
        │                                                   │
        │  4. Получает расчет + КП                          │
        │←─────────────────────────────────────────────────│
        │                                                   │
        │  5. Вносит предоплату 50%                         │
        │─────────────────────────────────────────────────→│
        │                                                   │
        │  6. KERAMO закупает материал + режет              │
        │                    ↓                              │
        │            [ПРОИЗВОДСТВО]                         │
        │                    ↓                              │
        │  7. Мастер + монтажник доставляют и укладывают   │
        │     на стены                                      │
        │←─────────────────────────────────────────────────│
        │                                                   │
        │  8. Клиент принимает работу, платит 50%          │
        │─────────────────────────────────────────────────→│
        │                                                   │
        │  9. Гарантия 1 год                                │
        │←─────────────────────────────────────────────────│
```
