## Процесс продажи

### Этап 1: Обработка заявки (30 минут)

| Действие | Ответственный | Инструмент |
|----------|---------------|------------|
| Заявка из Instagram | SMM | Direct / WhatsApp |
| Перенос в CRM | Менеджер | Bitrix24 (бесплатный) |
| Первый звонок | Менеджер | Телефон |

**Скрипт первого звонка:**
1. Представиться
2. Уточнить объект (ванная/кухня/стены)
3. Уточнить адрес и примерную площадь стен
4. Предложить бесплатный замер
5. Назначить время

### Этап 2: Замер (1-2 часа)

| Действие | Ответственный |
|----------|---------------|
| Выезд на объект | Мастер или Менеджер |
| Замеры стен | Рулетка + лазер |
| Фото объекта | Телефон |
| Обсуждение материала | С каталогом |

### Этап 3: Расчет и КП (1 день)

| Действие | Инструмент |
|----------|------------|
| Расчет площади стен + подрезка | Excel/Google Sheets |
| Расчет погонных метров нарезки | Excel |
| Подбор материала | Каталог + остатки |
| Формирование КП | Шаблон в Canva |
| Отправка клиенту | WhatsApp |

### Этап 4: Закрытие сделки

| Действие | Условие |
|----------|---------|
| Договор | Шаблон в Google Docs |
| Предоплата 50% | Kaspi QR |
| Заказ материала | Если нет на складе |
| Назначение даты | Согласование с бригадой |

### Этап 5: Выполнение + закрытие

| Действие | Ответственный |
|----------|---------------|
| Резка (пог.м) | Резчик |
| Доставка | Монтажник + Газель |
| Монтаж на стены | Бригада |
| Фото/видео результата | SMM-мобилограф |
| Оплата остатка 50% | Клиент |
| Акт выполненных работ | Менеджер |
| Запрос отзыва | Менеджер |
